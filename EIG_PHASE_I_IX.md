# Part II. Phase-by-phase mathematical record

# 4. Phase I - observer-relative feedback semantics

## 4.1 Original North Star

The earliest programme sought a scale-free **Projective Interaction Decomposition**: one invariant or small collection of invariants that would split finite-interface recurrent/tropical systems into tame regions and a wild recurrent core, support serial/parallel/gluing laws, and ideally yield obstruction/tangle structure.

The strongest scalar version did not survive. Fixed-state recurrent examples, triangular/decorated feedback, and guarded arithmetic showed that local state dimension and static width do not control recurrent semantic complexity.

The mathematical problem contracted to:

> Given the raw feedback syntax and an observer family, what is the exact semantic quotient seen by all admitted contexts, and what can or cannot be effectively recognized about it?

## 4.2 Theorem I.1 - exact first-return-star entrance

**PROVED / standard shell.** Let `G` be a finite directed control graph and `F` a finite set meeting every directed cycle. Suppose path values compose in a category/semiring supporting finite sums/unions and a Kleene star of the finite `F x F` first-return matrix `M_F`.

Every path contributing to the public query either avoids `F` or has a unique decomposition

```text
entry to F
; zero or more F-to-F first-return excursions
; exit from F.
```

Hence

```math
\operatorname{Ans}(T,\Psi)
=
\operatorname{Ans}(T\setminus F,\Psi)
\cup
C_{\Psi,F}M_F^*D_{F,\Psi}.
```

### Proof

Because `F` meets every cycle, `G-F` is acyclic. For a path that visits `F`, cut it at its first visit, between consecutive visits, and at its last visit. The middle factors are exactly first-return excursions with no internal `F` vertex. The cut positions are unique. Conversely every compatible sequence of such factors is a path. Summing over the number of middle excursions gives

```math
I+M_F+M_F^2+\cdots=M_F^*.
```

Nothing in the public query has changed; only the internal evaluation has been reorganized. ∎

## 4.3 Theorem I.2 - observer-indexed fully abstract quotient

Let `A` be the feedback closure in the declared signature and let `O` be the admitted observer family. Define

```math
a\equiv_O b
\iff
O_i(xay)=O_i(xby)
```

for every observer `O_i` and every well-typed pair of left/right contexts `x,y`.

**PROVED.**

1. `equiv_O` is a congruence.
2. It is the largest congruence contained in every observer kernel.
3. `Omega_O(A)=A/equiv_O` is fully abstract.
4. If `h:A -> B` is any surjective homomorphic exact summary from which every observer can be decoded, then `ker h subseteq equiv_O`; hence there is a unique surjection

   ```math
   B\twoheadrightarrow\Omega_O(A)
   ```

   through which the quotient factors.

Thus `Omega_O(A)` is the least-information exact homomorphic observer summary.

### Proof

If `a equiv_O b`, multiplication or any declared compatible operation can be absorbed into the quantified contexts; e.g.

```math
O_i(x(ca)y)=O_i((xc)ay)=O_i((xc)by)=O_i(x(cb)y).
```

Hence the relation is a congruence. If `theta` is any observer-sound congruence and `a theta b`, then `xay theta xby`, so every observer agrees; therefore `theta subseteq equiv_O`.

For the factorization claim, if `h(a)=h(b)`, homomorphicity gives `h(xay)=h(xby)` in every context, and decodability gives equal observer values. Hence `a equiv_O b`. Define

```math
\bar h(h(a))=[a]_{\equiv_O}.
```

Kernel inclusion makes this well-defined, and surjectivity of `h` gives uniqueness. ∎

## 4.4 Theorem I.4 - minimal hard-core localization

**PROVED under closure hypotheses.** In a class of finite atlases closed under transition deletion and reachable-SCC restriction, suppose semantic tameness is closed under finite union, source-target restriction, acyclic composition, and insertion of tame first-return pieces. Then a deletion-minimal counterexample has a strongly connected hard region. Deleting any chosen vertex `h` makes the remainder tame, every first-return `h -> h` kernel through the deletion is tame, and all remaining non-tameness is concentrated in the star of that first-return kernel.

### Proof core

If the condensation DAG of the hard region had several SCCs, minimality would make every proper component tame and acyclic composition would make the whole object tame, contradiction. After deleting `h`, each first-return excursion is a finite union of

```text
outgoing h-edge
; restricted semantics of G-h
; incoming h-edge.
```

Closure gives tameness of the kernel; the first-return identity localizes the remaining failure to its star. ∎

## 4.5 Theorem I.5 - fixed-template two-sided non-r.e. wall

**PROVED in the audited transparent scalar atlas model.** Both

```text
LOW  = {encodings with Presburger-definable fixed-query feedback answer}
HIGH = {encodings with non-Presburger fixed-query feedback answer}
```

are not recursively enumerable.

The proof uses one fixed deterministic two-counter Minsky machine and one fixed finite Presburger transition template. Only an initialization numeral varies.

### Proof architecture

Encode counters in prime exponents and the simulated control state in a residue class. Two modes are built into the same fixed template.

**Mode A.** Add a time factor `5^t` to the payload. A nonhalting run produces an observed unary sequence with unbounded successive gaps, hence a non-Presburger set; a halting run produces only finitely many exposed cumulative records. Therefore

```math
e\notin HALT\iff d_A(e)\in HIGH.
```

Since the complement of the halting set is not r.e., `HIGH` is not r.e.

**Mode B.** Keep every simulation-edge record zero. On halt, enter a fixed doubling loop whose cumulative records are

```math
\{0\}\cup\{N(2^k-1):k\ge0\},
```

again non-Presburger by unbounded gaps. If the machine never halts the answer is `{0}`. Thus

```math
e\notin HALT\iff d_B(e)\in LOW,
```

so `LOW` is not r.e. either. ∎

# 5. Phase II - future residuals and observable action

## 5.1 Why Phase II was forced

The Phase-I quotient is two-sided and extensional. Algorithms often need a **one-sided state** that can be advanced deterministically and tells exactly which continuations remain legal.

Let `X` be the typed state set and `A` a finite alphabet of partial letters. Each letter has a guard `G_a` and deterministic update

```math
F_a:G_a\to X.
```

For a word `w`, let

```math
D_w=\{x:w\text{ is legal from }x\}.
```

Define future equivalence

```math
x\equiv_{fut}y
\iff
\forall w\in A^*:\quad
w\text{ legal from }x
\Leftrightarrow
w\text{ legal from }y.
```

## 5.2 Theorem II.4 - future-legality Myhill-Nerode theorem

**PROVED / standard minimization shell.** The following are equivalent:

1. `equiv_fut` has finite index;
2. there is a finite stable future partition;
3. the Boolean algebra generated by all `D_w` and closed under guarded inverse image is finite.

When finite, the future classes are the atoms of that Boolean algebra and form the unique coarsest stable deterministic partition.

### Proof

The domains satisfy

```math
D_\varepsilon=X,
\qquad
D_{av}=G_a\cap F_a^{-1}(D_v).
```

If two states have the same future language, one-letter legality gives equal guard membership, and

```math
v\text{ legal from }F_a(x)
\iff av\text{ legal from }x
\iff av\text{ legal from }y
\iff v\text{ legal from }F_a(y),
```

so the future quotient is stable.

Conversely, legality of every word is constant on a stable block by induction on word length; hence every stable partition refines future equivalence.

If there are `n` future classes, every `D_w` is a union of those classes, so the Boolean algebra has at most `2^n` elements. Conversely, atoms of a finite Boolean algebra generated by the `D_w` are exactly states sharing all word-domain predicates. ∎

## 5.3 Counterexample II.6 - infinite future index is not global wildness

On `N`, let the only letter decrement when positive. From state `n`, exactly words of length at most `n` are legal. Every state has a different future language, so the index is infinite, yet legality is just `k<=n` and reachability is elementary.

Thus finite future index is an exact structural property, not a synonym for decidability.

## 5.4 Theorem II.7 - observable affine-action reduction

In the scoped one-counter/affine setting, quotient reachable coefficient states by equality under all future legal continuations and public affine readouts. The resulting action `M_obs` is the unique coarsest future-observable coefficient action.

**PROVED under the declared one-counter hypotheses.** If `M_obs` is finite and initialized intercept contributions are affine functions of the admitted Parikh/count data, then the complete public input/output relation is effectively Presburger-definable.

### Proof core

Take the product of

```text
finite control
x finite observable coefficient state
x one nonnegative legality counter.
```

This is an effective one-counter net. Accepted word languages are context-free/one-counter and have effectively semilinear Parikh images. Affine images of semilinear sets are Presburger-definable. The raw coefficient monoid may be infinite; only its future-observable quotient matters. ∎

## 5.5 Discovery consequence

Phase II separated

```text
semantic equality
from
minimal advanceable future state.
```

It produced the canonical `Q`-type component, but the next failure was immediate: future equivalence can erase intermediate resources that become visible after gluing.

# 6. Phase III - the process object is not its final relation

## 6.1 The decisive counterexample

Let

```math
B=\langle p,q\mid pq=1\rangle
```

be the bicyclic monoid. Consider two one-step open components

```text
A: 1 --p--> p
B: p --q--> 1.
```

Separately, neither has a neutral run from identity to identity. If one first applies the neutral/public projection, both visible relations are empty.

But raw composition retains the intermediate port:

```text
1 --p--> p --q--> 1,
```

and `pq=1`, so the composite has a valid neutral run.

Therefore

```text
project/neutralize first; then compose
```

is not equivalent to

```text
compose raw complete ports; then project/neutralize.
```

This is the smallest historical reason EIG had to become more than contextual quotienting.

## 6.2 Counterexample III.2 - net effect is not enough

Under the partial counter action, `p` increments and `q` decrements when positive. The words `pq` and `qp` have the same net integer effect zero, but from depth zero `pq` is legal and `qp` is not.

Prefix debt and intermediate exposure survive even when net effect agrees.

## 6.3 Counterexample III.3 - unsealed subdivision changes behavior

In the free product of two bicyclic resources, a sealed neutral macro `a abar` can cease to be neutral if its internal boundary is exposed and another component interleaves:

```text
a b abar bbar.
```

The alternating free-product word does not reduce to identity. Thus arbitrary macro subdivision is not an exact recoding; only sealed refinement is.

## 6.4 Theorem III.4 - exposed transactional composition

Represent every primitive occurrence `e` by a span

```math
X_{s(e)}\xleftarrow{\ell_e}W_e\xrightarrow{r_e}X_{t(e)},
```

where `W_e` carries the chosen storage word and every later-readable decoration.

**PROVED in the declared exposed transactional doctrine.**

1. sequential composition is pullback over complete intermediate states;
2. composition is associative up to canonical pullback isomorphism;
3. nondeterministic choice is disjoint union;
4. finite iteration is free-path/Kleene-star closure;
5. neutral/public observation is applied after raw composition;
6. typed renaming, inert pointed padding, sealed refinement, and deterministic observer product are exact recodings;
7. equality of final public relations is not an exact recoding criterion.

### Proof

The composite apex of `e` and `f` is

```math
W_e\times_{X_{t(e)}}W_f.
```

Associativity is the universal pullback associator. Free paths give

```math
I+M+M^2+\cdots.
```

The neutral predicate is a restriction of the final composite apex. Applying it earlier can delete a witness later needed in a pullback, exactly as the `p;q` counterexample shows. ∎

## 6.5 Discovery consequence

The emerging object now had two irreducible layers:

```text
semantic quotient
+
lossless raw interface/witness structure.
```

The latter cannot in general be recovered from the former.

# 7. Phase IV - carrier geometry, chart moduli, and descent

## 7.1 Why Phase IV was forced

Phase III said what must not be forgotten, but not how the retained ports and occurrences should be localized and reconstructed from overlapping pieces.

Inside the normalized protected domain `Proc_prot^0`, let `V(P)` be the literal resource set. Define `K_min(P)` by forcing an edge whenever two resources must coexist because they appear together in:

1. a protected support/hull piece;
2. a storage/zipper compatibility constraint;
3. the total footprint of one unsplit primitive occurrence.

Higher-arity footprints are made cliques.

## 7.2 Theorem IV.2 - unique least carrier

**PROVED.** `K_min(P)` is the unique least admissible carrier under edge inclusion.

### Proof

Let `E_req` be the union of all pairs that must co-occur. Every admissible carrier contains every pair in `E_req`; `K_min=(V,E_req)` itself makes every required set a clique. Hence it is admissible and contained in every admissible carrier. ∎

## 7.3 Theorem IV.4 - all-chart clique criterion

For a finite graph `K` and finite set `H`, the following are equivalent:

1. `H` is a clique;
2. every tree decomposition of `K` has a bag containing all of `H`.

### Proof

If `H` is a clique, the bags containing each vertex form connected subtrees, and every pair of those subtrees intersects because the corresponding edge is contained in some bag. Finite subtrees of a tree satisfy Helly, so all intersect in one bag.

If `H` is not a clique, choose nonadjacent `u,v in H`. The two bags

```math
V(K)\setminus\{u\},
\qquad
V(K)\setminus\{v\}
```

joined by an edge form a tree decomposition containing every graph edge but no bag containing both `u,v`. ∎

## 7.4 Why one chart is not canonical

A process can admit several exact normalized tree decompositions with no invariant way to choose one. Phase IV therefore keeps

```text
Chart_can(P)
```

as a finite groupoid/moduli of admissible charts rather than declaring one tree canonical.

This is the first strong historical example of an EIG endpoint being canonical **as a moduli object** without a canonical representative.

## 7.5 Complete ports and occurrence ownership

Given a chart, each bag/separator/owner region displays reference views of one global protected allocation. The views retain stable global identity and all later-readable fields.

For a primitive occurrence, its total footprint is a clique and hence lies in a connected nonempty subtree of bags. Root a chart; assign the occurrence to the unique bag in that subtree nearest the root. Repeated overlap appearances are references to the same occurrence, not independent copies.

## 7.6 Theorem IV.6 - spans as witness matrices

For a span

```math
X\xleftarrow{s}W\xrightarrow{t}Y,
```

there is a canonical decomposition

```math
W\cong\coprod_{(x,y)}W_{x,y}.
```

Pullback composition becomes matrix multiplication in `Set`:

```math
(W\odot V)_{x,z}
\cong
\coprod_y W_{x,y}\times V_{y,z}.
```

The fibres retain multiplicity and provenance that the support relation forgets.

## 7.7 Theorem IV.7 - owner Cech codescent reconstruction

Under the protected owner-cover hypotheses - connected appearance categories, stable identities, exhaustive coverage, and unsplit joint primitives - the canonical comparison

```math
\operatorname*{colim}_I Q(U_I)\longrightarrow Q(U)
```

is an isomorphism of decorated atomic quivers. Applying the labelled free-category functor reconstructs the full finite-path execution category.

### Proof core

In a colimit of sets, copies of an element are identified along connected components of its appearance category. Each global state and each global primitive has a nonempty connected appearance simplex; distinct global identities are never locally identified. Therefore each global state/occurrence contributes exactly one colimit element and every element appears. The free-category functor preserves colimits because it is left adjoint to the underlying-quiver functor. ∎

## 7.8 Theorem IV.9 - compose first, recanonicalize the target

For composable protected processes `P,R`, the Book-level composite is:

```text
raw span/occurrence composition
-> final target ledger
-> newly fused total footprints
-> K_min(target)
-> Chart_can(target)
-> complete ports / owner descent / recurrence / observation.
```

Pushing out chosen source charts is not sound: a new joint primitive can force a clique absent from either source carrier.

Associativity is inherited from span composition and transported through the uniquely derived target carrier and chart groupoid. The result is pseudofunctorial/canonical-equivalence associativity, not literal equality of chosen chart trees.

## 7.9 Counterexample IV.10 - extensional equality does not determine carrier geometry

A ternary equality occurrence on `{x,y,z}` forces a `K_3` footprint. A factorized presentation using binary equalities `x=y` and `y=z` forces a path-shaped primitive footprint. Their external relation can agree while attachment and witness provenance differ.

Thus carrier geometry is canonical relative to native factorization, not final extensional relation alone.

## 7.10 Discovery consequence

The process object had acquired genuine geometry:

```text
least carrier
+
chart moduli
+
complete local interfaces
+
owner/descent structure
+
recanonicalization under composition.
```

“Geometry” here meant gluing, fibres, decomposition and moduli, not metric space geometry.

# 8. Phase V - interface before valuation

## 8.1 Principle V.1

The structural interface across a cut is the isomorphism class of the complete restriction/witness object sufficient for exact raw gluing.

A width, rank, dimension, entropy, or communication cost is a **valuation of that object**.

```text
operational doctrine
-> exact interface Sigma
-> valuation mu
-> scalar lambda = mu(Sigma).
```

This order was forced by Phase IV: different numerical coordinates varied independently while the exact gluing object stayed fixed.

## 8.2 Theorem V.2 - linear/lattice connectivity is submodular

Let `L subseteq direct_sum_{v in V} E_v` be finite-dimensional. Put

```math
r(A)=\dim \pi_A(L),
\qquad
\lambda_L(A)=r(A)+r(V\setminus A)-r(V).
```

**PROVED / standard.** `lambda_L` is normalized, symmetric, and submodular.

### Proof

Projection rank is a polymatroid rank function. Apply submodularity to `A,B` and to their complements, add, and cancel `2r(V)`. ∎

## 8.3 Theorem V.3 - conflict-graph characterization

For `R subseteq X x Y`, form the conflict graph whose accepted pairs `(x,y),(x',y')` are adjacent when at least one cross-pair is absent.

The minimal Presburger channel dimension equals the least `d` for which the conflict graph admits a Presburger-definable proper coloring into

```math
F\times\mathbb Z^d
```

with `F` finite.

### Proof

A factorization through a witness `(f,z)` colors every accepted pair by a chosen witness. Equal-colored pairs share a witness, so both cross-pairs are accepted and the color class is independent.

Conversely, from a proper coloring define the left and right witness predicates by existentially projecting accepted pairs of that color. Properness guarantees cross-mixing remains accepted, reconstructing the factorization. ∎

## 8.4 Theorem V.5 - zero cuts of an affine semigroup

Let `M subseteq N^V` be a finitely generated affine semigroup and `C=cone_R(M)`. For a cut `A|B`, let `C_A,C_B` be the shore-supported subcones.

**PROVED.**

```math
\lambda_M(A)=0
\iff
C=C_A+C_B.
```

Hence zero cuts are exactly unions of connected components of the hypergraph of extreme-ray supports and form a Boolean algebra.

### Proof core

If channel dimension is zero, `M` is a finite union of rectangles. Apply the rectangle property to arbitrarily large multiples `nv` of a semigroup element and cross-mix two multiples. After scaling and passing to the cone, both shore projections of `v` lie in `C`, giving `C=C_A+C_B`.

Conversely, cone splitting implies that suitable multiples of each finite generator lie in `M_A+M_B`. Reducing coefficients modulo those multiples leaves finitely many remainders, so

```math
M=\bigcup_{f\in F}(f_A+M_A)\times(f_B+M_B),
```

which is a finite rectangle cover. ∎

## 8.5 Corollary V.6 - submodular envelope

Count extreme rays whose support crosses a cut:

```math
c_C(A)=\#\{\rho:\operatorname{supp}(\rho)\text{ crosses }A|Abar\}.
```

Then `c_C` is symmetric submodular,

```math
\lambda_M(A)\le c_C(A),
\qquad
c_C(A)=0\iff\lambda_M(A)=0.
```

Thus a useful submodular shadow can preserve exactly the zero-cut geometry without equaling the exact interface cost.

## 8.6 Theorem V.7 and Counterexample V.8 - exact boundary of affine submodularity

**PROVED.** Every affine semigroup on at most four coordinates has submodular channel dimension.

**COUNTEREXAMPLE / NO-GO.** In five coordinates let

```math
S=\{x\in\mathbb N^5:
 x_1+x_3\le x_4+x_5,
 x_4\le x_1+x_2+x_3+x_5,
 x_3+x_5\le x_4\}.
```

`S` is a full-dimensional normal affine semigroup. For

```math
A=\{1,2\},
B=\{2,3\},
I=\{2\},
U=\{1,2,3\},
```

one obtains

```math
\lambda_S(A)=\lambda_S(B)=\lambda_S(I)=1,
\qquad
\lambda_S(U)=2.
```

Therefore

```math
\lambda_S(A)+\lambda_S(B)=2
<3=\lambda_S(A\cap B)+\lambda_S(A\cup B).
```

### Proof mechanism for the lower bound `lambda_S(U)>=2`

For `0<=r,s<=N`, take

```math
p_{r,s}=(2r,0,s,r+s,r).
```

These points lie in `S`. If both cross-mixes of `p_{r,s}` and `p_{r',s'}` across `U|{4,5}` are accepted, the third defining inequality forces `s=s'`, and the first then forces `r=r'`. Hence the `(N+1)^2` points form a clique in an `O(N)` box. A Presburger coloring into `Z^d` has only `O(N^d)` colors on such a box, so `d>=2`. ∎

## 8.7 Discovery consequence

Phase V killed the idea that “interaction geometry” means one universal rank-like scalar. The structural object is the interface; scalars are secondary observables on it.

# 9. Phase VI - lossless noncopying reduction

## 9.1 Why semantic minimization is not interaction minimization

`Omega_O(P)` is minimal for the **current observer**. But a boundary can later be reopened, at which point information erased by `Omega_O` can become compositionally necessary.

A lossless reduction has the opposite obligation: preserve exactly enough to reconstruct and compose.

## 9.2 Definition VI.1 - `RedInt(P)`

For `P in Proc_prot^0`, the protected reduced interaction object contains:

```text
Chart_can(P)
owner regions and required intersections
complete port-state reference views
uniquely owned decorated primitive occurrences
span/proarrow matrices
path and recurrent-star syntax
chart/face/evaluator transport.
```

“Reduced” means derived, noncopying, and finitely schematized. Local state sets may still be infinite.

## 9.3 Theorem VI.2 - strong protected reduction

**PROVED in `Proc_prot^0`.** `RedInt(P)` is:

1. derived from the uncharted native process;
2. noncopying at primitive-occurrence level;
3. exact for owner-Cech reconstruction;
4. equivariant under native recodings/chart changes;
5. feedback-stable in the product-before-star sense;
6. composition-stable by raw-target-first recanonicalization.

### Proof

This is the simultaneous application of the Phase-IV least-carrier, complete-port, owner-codescent and target-recanonicalization theorems. Noncopying follows because every primitive has one owner or one explicit unsplit joint apex; overlap displays share one identity rather than duplicating a variable. ∎

## 9.4 Strict separation from observer quotient

Counterexample III.1 immediately gives

```text
Omega_O(P) != RedInt(P)
```

in general. The public quotient deletes the intermediate `p` port; `RedInt` retains it and therefore reconstructs the accepted composite.

## 9.5 Counterexample VI.4 - reconstructivity alone is vacuous

Attach the entire global process `P` to every cut. Reconstruction is trivial, but the same global information is copied everywhere and any naive “number of interface records” width is one.

Therefore a meaningful reduction theorem needs noncopying/information-load conditions, not reconstruction alone.

## 9.6 Theorem VI.5 - no nontrivial all-function coarse-graining of bare sets

Suppose every set `X` is assigned an equivalence relation `E_X`, natural under every function:

```math
xE_Xy\Rightarrow f(x)E_Yf(y).
```

**PROVED.** Either every `E_X` is equality or every nonempty `E_X` is indiscrete.

### Proof

If some `E_X` identifies distinct `x,y`, let `Y` be any nonempty set and choose arbitrary `a,b in Y`. A function with `f(x)=a,f(y)=b` gives `aE_Yb`. Since `a,b` were arbitrary, `E_Y` is indiscrete. If no distinct pair is ever identified, all relations are equality. ∎

This is a small but decisive no-go: nontrivial canonical reduction requires a doctrine richer than bare sets with all functions.

# 10. Phase VII - arities, nerves, and world-relative reconstruction

## 10.1 The new question

Once a lossless reduced object exists, can a small family of interaction shapes reconstruct the entire world?

Phase VII answered “yes, relatively” and “no, density does not make the family canonical.”

## 10.2 Theorem VII.1 - relative path nerve

Let `B` be a small category and `Path(B)` the full subcategory of `Cat/B` on finite ordinal paths `[n]->B`. Define

```math
N_B(C)(u)=Cat/B(u,C).
```

**PROVED / standard.**

```math
N_B:Cat/B\to[Path(B)^{op},Set]
```

is fully faithful. Its essential image satisfies the unit and strict Segal conditions relative to `B`.

### Proof

Values on `[0]` recover objects; values on `[1]` recover arrows and labels; endpoint maps recover source/target; degeneracy recovers identities; maps involving `[2]` recover composition. Naturality of a transformation therefore forces exactly a functor over `B`.

Conversely, the Segal isomorphisms

```math
X_n\cong X_1\times_{X_0}\cdots\times_{X_0}X_1
```

reconstruct composable strings and hence a category over `B`. ∎

## 10.3 Theorem VII.2 - incidence representation

For a directed multigraph `G`, let `I_G` have one object for each vertex and edge, and the two incidence arrows from endpoint vertices to each edge object.

**PROVED / standard.**

```math
Quiv/G\simeq[I_G^{op},Set].
```

Under free-category completion this is equivalent to the free ULF-run category over `Free(G)`.

### Proof

A quiver over `G` is exactly a family of vertex fibres `X_v`, edge fibres `X_e`, and source/target maps `X_e->X_v,X_e->X_w`; that is precisely a presheaf on `I_G`. Free paths have unique cuts into primitive edge labels, giving the ULF property. ∎

## 10.4 Corollary - path witness fibres are iterated pullbacks

For a labelled path `e_1...e_n`, its witness set is

```math
X_{e_1}\times_{X_{v_1}}X_{e_2}
\times\cdots\times_{X_{v_{n-1}}}X_{e_n}.
```

Thus primitive edge/vertex fibres reconstruct all finite path witnesses.

## 10.5 Counterexample VII.5 - density is not selection

In `Set`, the one-object subcategory `{1}` is dense because

```math
Hom(1,X)\cong X.
```

`FinSet` is also dense by the ordinary density theorem. These probe categories are not equivalent.

Hence “this family gives a fully faithful nerve” does not imply “this is the canonical family of primitive shapes.”

## 10.6 Theorem VII.6 - no fixed probes survive arbitrary extension

Let `A` be any fixed small probe family in `C`. Adjoin two new isolated objects `u,v` with no arrows from any `a in A`. Then

```math
D(a,u)=\varnothing=D(a,v)
```

for every probe, so the restricted nerves of `u` and `v` are identical. The probe family is not dense in the enlarged world.

## 10.7 Discovery consequence

Phase VII forced a new distinction:

```text
RECONSTRUCTION by a supplied/derived arity system
!=
INTRINSIC SELECTION of that arity system.
```

This is the precise problem inherited by Phase VIII.

# 11. Phase VIII - objecthood, atomic roots, and the no-smuggling crisis

## 11.1 The North Star

Phase VIII asked for an intrinsic chain

```text
REDUCE -> CLOSE -> RECONSTRUCT
```

in which the primitive interaction shapes, ports, owners, arities, and process Homs were not simply supplied as labels.

This phase is where the project most sharply learned the difference between **having a representation theorem** and **having identified the represented structure intrinsically**.

## 11.2 Theorem VIII.1 - marked atomic nerve reconstruction

Let `C` be locally small, `A` a small full subcategory, and `Sigma` a marked class of colimit presentations. Assume every `X` has a marked presentation

```math
X\cong\operatorname{colim}_i A_i
```

with `A_i in A`, and every `A in A` is `Sigma`-atomic:

```math
\operatorname{colim}_i C(A,A_i)
\xrightarrow{\cong}
C(A,\operatorname{colim}_i A_i).
```

Then the restricted nerve

```math
N_A:C\to[A^{op},Set]
```

is fully faithful.

### Proof

Faithfulness: if `f,g:X->Y` agree after precomposition by all maps from `A`, then they agree on every coprojection of a marked `A`-presentation of `X`; the colimit universal property gives `f=g`.

Fullness: for a natural transformation `tau:N_A(X)->N_A(Y)`, apply it to the coprojections `u_i:A_i->X` to obtain `v_i:A_i->Y`. Naturality makes the `v_i` a cocone, hence a unique `f:X->Y`. Atomicity factors every `u:A->X` through some `u_i`, and naturality then gives `tau_A(u)=fu`. ∎

The theorem is exact, but **marked**: the class `A` and the admissible presentations are input.

## 11.3 Theorem VIII.2 - atomic objects are the Karoubi closure

Under the displayed hypotheses and idempotent completeness,

```math
At_\Sigma(C)=Kar_C(A).
```

### Proof

Retracts of atomic objects remain atomic. Conversely, if `X` is atomic and

```math
X=\operatorname{colim}_i A_i,
```

then preservation of this colimit by `C(X,-)` implies that `1_X` comes from some stage, yielding maps

```math
X\to A_i\to X
```

whose composite is `1_X`. Thus `X` is a retract of an object of `A`. ∎

## 11.4 Theorem VIII.4 - minimal response image

For a response table `r:X x Y -> W`, define

```math
\rho:X\to W^Y,
\qquad \rho(x)(y)=r(x,y),
```

and `Q_r=im rho`.

Any exact deterministic summary `h:X->>S` through which `r` decodes admits a unique surjection `S->>Q_r`.

The proof is the direct kernel argument:

```math
h(x)=h(x')\Rightarrow r(x,y)=r(x',y)\quad\forall y,
```

so `rho` factors uniquely through `h`.

## 11.5 Theorem VIII.5 - a noncircular native reduction chain

Inside the fixed native protected domain, the following chain is genuinely derived stage by stage:

```text
raw primitive relations/spans/storage
-> endpoint fibre tabulation and response images
-> protected support/storage fibres
-> total footprints
-> K_min
-> all exact chart moduli
-> chart-relative complete ports and owners
-> owner Cech reconstruction
-> path/recurrent execution.
```

Every arrow depends only on earlier raw or already-derived data. Therefore the chain is noncircular **inside that native presentation doctrine**.

It does not prove that the native primitive relations themselves are recoverable from an unmarked extensional world.

## 11.6 Theorem VIII.6 - tiny objects recover only the Cauchy root

For a small category `A`, in

```math
PSh(A)=[A^{op},Set],
```

an object `P` is tiny/small-projective iff it is a retract of a representable. Therefore

```math
Tiny(PSh(A))\simeq Kar(A).
```

### Proof

Representables are tiny by Yoneda and retracts preserve tininess. Conversely every presheaf has its category-of-elements presentation

```math
P\cong\operatorname{colim}_{(a,x)\in\int P} y(a).
```

If `P` is tiny, applying `PSh(A)(P,-)` preserves this colimit; the identity `1_P` must arise from one representable stage, giving a retraction

```math
P\to y(a)\to P.
```

Thus the world remembers the presenting category only up to Cauchy/Karoubi completion. ∎

This was a major correction to any demand for literal primitive-presentation uniqueness.

## 11.7 No-go VIII.9 - smuggled extractor criterion

Let

```math
U:MarkedWorld\to World
```

forget marked primitive data `A`.

An alleged extractor defined on `(W,A)` by returning `A` is not an extractor from `W` unless it descends through `U`. If the same unmarked `W` admits two markings `A,A'`, a genuine unmarked extractor must assign one output determined from `W`, and the two recovered markings must be canonically equivalent by a theorem that does not consult the mark.

This criterion invalidated an early marked recurrent `REDUCE`: its input already contained complete ports, residual data, owners or covers it claimed to derive.

## 11.8 Counterexample VIII.10 - ambient Hom is not process Hom

Let the ambient category be `Set`, but intended process morphisms be surjections. There are two functions

```text
1 -> 2
```

and zero surjections. Ambient Yoneda full faithfulness reconstructs two maps, not the intended empty Hom.

Therefore an ambient nerve theorem does not establish full faithfulness for a stricter process category unless the morphism class is itself encoded and proved correct.

## 11.9 Counterexample VIII.11 - disconnected primitive and path probes miss the bridge

If the arity category is merely a disjoint union

```math
J_c\sqcup Lin(c),
```

then its presheaf category is a product. A natural transformation may independently permute the primitive-generator component and fix the path component. Such a transformation need not preserve the intended generator-to-composite relation and therefore need not come from a process morphism.

The mixed bridge is mathematical data; it cannot be inferred from two disconnected dense sectors.

## 11.10 Counterexample VIII.12 - tabulation choice has isotropy

The span

```math
1\leftarrow\{0,1\}\to1
```

has the nontrivial automorphism exchanging `0` and `1`. Its tabulation groupoid therefore has isotropy `S_2` and is not contractible.

Existence of tabulations does not imply a canonical witness frame. The correct endpoint may be a groupoid/moduli.

## 11.11 Counterexample VIII.13 - specieswise quotient can destroy operations

Let `X=Y={0,1}` and `f:X->Y` be the identity. Give `X` a constant response so its response quotient is one point; give `Y` the identity response so its quotient is still two points.

There is no descended map from the one-point quotient of `X` to the two-point quotient of `Y` compatible with both `f(0)=0` and `f(1)=1`.

Hence one cannot quotient each species independently and assume the cross-species doctrine survives.

# 12. Phase IX - doctrine-relative recognition and the canonicality ceiling

## 12.1 The North Star

with both round trips controlled at the strongest honest equivalence level.

The decisive audit question was:

## 12.2 No-go IX.1 - `Span(Set)` versus `Rel(Set)`

In standard scopes,

```math
Map(Span(Set))\simeq Set,
\qquad
Map(Rel(Set))\simeq Set.
```

Yet the interaction theories differ.

Consider the two spans

```math
1\leftarrow1\to1,
\qquad
1\leftarrow2\to1.
```

They have the same support relation but nonisomorphic apexes and different witness multiplicity. Relation semantics records only whether a witness exists; span semantics can retain how many and which witnesses exist.

**NO-GO.** The ordinary map world does not determine a unique doctrine-free `Interaction(World)`.

### Proof

In `Span(Set)`, map/left-adjoint spans are, up to isomorphism, exactly spans arising from functions. In `Rel(Set)`, maps are functional relations. Both recover `Set` as map core.

But

```math
Span(Set)(1,1)\simeq Set,
```

while `Rel(Set)(1,1)` has only the empty and total relation. The two interaction bicategories are not equivalent in a way that preserves the displayed map core and witness semantics.

Thus any choice between them from `Set` alone inserts information not present in the input. A global convention may choose one, but that convention is extra structure rather than a canonically identified invariant. ∎

This is the exact obstruction that stopped the strongest doctrine-free interpretation of interaction primacy.

## 12.3 Positive doctrine-relative recognition sectors

The negative result does not say intrinsic recognition is impossible. It says the doctrine matters.

The Phase-IX audit records standard positive sectors:

### Spans

Under the appropriate cartesian-bicategorical/span hypotheses, the map/left-adjoint locus recovers the base and the bicategory is characterized by span universal properties.

### Relations / allegories

Under the standard tabular unitary allegory/regularity hypotheses, maps recover a regular category and the allegory is equivalent to its relation calculus.

### Profunctors and Cauchy/Morita equivalence

A left-adjoint profunctor into a Cauchy-complete target is representable. Presheaf/profunctor semantics naturally identifies presenting categories only up to Cauchy/Morita equivalence.

### Versatile collage/collapse recognition

Kawase's 2026 AVDC theorems characterize profunctor/module completions internally under versatile collage or collapse hypotheses and recover an internally recognizable dense/atomic core up to admissible equivalence.

These are prior-art calibrations. Their historical role was to show that “canonical relative to a fixed doctrine” is mathematically substantive rather than arbitrary.

## 12.4 Theorem IX.7 - doctrine-relative does not mean arbitrary

A completion deserves the label **canonical relative to doctrine `D`** only if:

1. `D` is fixed independently of the target instance;
2. the completed essential image is characterized by internal `D`-properties;
3. the core/map locus is characterized internally;
4. extraction/completion round trips are controlled by a specified equivalence;
5. residual moduli and unselected frames are explicitly stated.

### Proof

Conditions 1-3 prevent target insertion. Condition 4 is the mathematical content of recognition rather than one-way construction. Condition 5 prevents an equivalence class from being misreported as a selected representative.

If instead one defines `D_W` after seeing `W` as “the doctrine whose completion returns `W`,” the essential-image theorem and extraction statement become true by definition. This is precisely the smuggling pattern isolated in Phase VIII. ∎

# 15. A strict total-sector semantic theorem

One common semantic skeleton can be isolated without pretending it contains the witness/descent layers.

Let `P` be a monoid with unit `1` and response `r:P->W`. Define

```math
p\equiv_Qp'
\iff
\forall y\in P:\ r(py)=r(p'y),
```

and

```math
a\equiv_Sb
\iff
\forall x,y\in P:\ r(xay)=r(xby).
```

Put `Q=P/equiv_Q` and `S=P/equiv_S`.

**THEOREM.**

1. `Q` is the unique coarsest deterministic exact future quotient.
2. Right multiplication descends to a faithful action of `S` on `Q`.
3. `q_0=[1]` is cyclic.
4. `o([p])=r(p)` is future-separating.
5. The response factors as

   ```math
   P\twoheadrightarrow S\curvearrowright Q\xrightarrow{o}W.
   ```

Conversely, any faithful action `S acts Q` with cyclic `q_0`, future-separating `o`, and surjective `P->S` has these canonical future and two-sided quotients.

### Proof

If `p equiv_Q p'`, then for every `a,y`,

```math
r(pay)=r(p'ay),
```

so the right action is well-defined. `equiv_S` is a two-sided congruence because contexts absorb multiplication on either side. If `a equiv_S b`, then `[pa]=[pb]` for every `p`, so the action factors through `S`.

Two elements of `S` induce the same transformation of `Q` exactly when

```math
r(xay)=r(xby)
```

for all `x,y`; therefore the descended action is faithful. Cyclicity is `[p]=[1]·[p]`. Future separation is the definition of `Q`.

For the converse, equality of future response profiles implies equality of `q_0·pi(p)` by future separation; cyclicity identifies the canonical future quotient with `Q`. Equality of two-sided profiles implies equality of the action on every `q`, and faithfulness then gives equality in `S`. ∎

This theorem is standard syntactic-transformation-monoid mathematics. Historically, its importance is to show exactly how much of the early semantic layer can be compressed into

```text
P ->> S acts Q -> W
```

and, equally importantly, what it omits: witness multiplicity, reopened interfaces, chart geometry, descent, arities, and doctrine selection.
