## 5. Exact common-interface CRT

For equivalence relations `alpha,beta` on `X`, consider

```text
X/(alpha intersect beta)
 -> X/alpha x_(X/(alpha join beta)) X/beta.
```

### Theorem V.2 — **AUDITED / ACCEPTED**
The map is bijective iff `alpha beta = beta alpha`.

Thus congruence permutability is an exact deterministic common-interface flatness condition. Mal'tsev/permutable settings are a broad positive sector.

## 6. Modular uncrossing

Suppose observation kernels satisfy

```text
theta_(A union B)=theta_A meet theta_B,
theta_A join theta_B <= theta_(A intersect B),
```

and `d` is a monotone modular valuation. Define `r(A)=D-d(theta_A)`.

### Theorem V.3 — **AUDITED / ACCEPTED**

```text
r(A)+r(B)-r(A intersect B)-r(A union B)
 = d(theta_(A intersect B))-d(theta_A join theta_B)
 >= 0.
```

The symmetric connectivity function `kappa(A)=r(A)+r(V-A)-r(V)` has slack equal to the sum of two shore residuals. In exact quotient sectors those residuals can be retained as objects, not merely numbers.
