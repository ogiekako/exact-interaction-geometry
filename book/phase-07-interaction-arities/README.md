# Phase VII — interaction arities

**Current status: generic arity shell CLOSED / KNOWN; project-specific Interaction-Arity Theorem OPEN / REDUCED.**

Phase VII asks the strongest reconstruction question in the programme:

> Can a small family of local interaction shapes reconstruct not just one state, but objects, morphisms, and the whole accessible mathematical world?

## 1. Finite residual interaction nerve

Let `E` be a finite coordinate set and

```text
F : product_(e in E) D_e -> O.
```

For `A subseteq E`, define the continuation row `res_A(a)(b)=F(a,b)` and quotient

```text
Q_A = im(D_A -> O^(D_(E-A))).
```

For disjoint `A,B`, joining assignments induces

```text
mu_(A,B):Q_A x Q_B -> Q_(A union B).
```

### Theorem VII.1 — residual interaction-nerve theorem
**AUDITED / ACCEPTED.**

The all-subset residual system is characterized by two properties:

1. **generator law** — gluing residuals agrees with gluing representatives;
2. **extensionality** — two local states are equal exactly when every complementary interaction gives the same root outcome.

Every extensional exact residual-arity datum reconstructs a unique tensor

```text
F_N(x)=epsilon(eta_E(x)),
```

and the reconstructed continuation quotients are canonically the original `Q_A`. On the stated typed-recoding groupoid, the residual nerve is fully faithful.

This theorem is a concrete “object from all local interactions” result. It does not yet identify the right arities for the full recurrent-process category.

## 3. What is actually new/project-specific

Choosing all finitely presentable presheaves after the world `PSh(W)` is given does **not** prove that the programme discovered the right local interactions. The strong theorem must derive the probes from the process theory itself.

### Target VII.4 — project-specific Interaction-Arity Theorem
**OPEN / REDUCED.**

Construct an explicit category

```text
A_IR = arities generated by the actual reduced Phase-IV/VI interfaces
```

and an explicit recurrent-process world `C_IR` (or monadic presentation) such that:

1. `A_IR` is small and intrinsic under admitted recodings;
2. its objects are noncopying/local interaction shapes, not arbitrary whole-state probes;
3. `A_IR` is dense in `C_IR`;
4. the relevant process constructor/monad is nervous for `A_IR`;
5. the essential-image axioms are exactly the programme's gluing, feedback, compatibility, and coherence laws.

A proof would turn Phase VI's reduced interfaces into a genuine reconstruction language for the whole process world.

## 4. Exact negative boundary

### Fixed-probe universality no-go
**AUDIT REPAIR / ACCEPTED AS A SHARP BOUNDARY.**

No fixed probe family can reconstruct arbitrary future category extensions. Adjoin two isolated nonisomorphic objects `x,y`; every old probe sees the same empty hom-data into both.

Therefore the right universality statement must be **world-generating or world-relative**. Interaction arities can be universal for a mathematical world they generate, not for every arbitrary category extension.

## 5. Relation to Yoneda

Ordinary Yoneda uses every representable in the category. Phase VII is more specific: it asks whether an explicitly generated **small local probe doctrine** is dense, and for algebraic worlds whether the relevant monad is nervous for those probes. Density/full faithfulness is standard; the project-specific content is deriving the probe doctrine from exact process interaction.

## 6. Why Phase VII matters for external consequences

If VII.4 is proved, the programme stops being merely a theory of one recurrent syntax. It gives a reusable procedure:

```text
find exact elementary interactions
 -> close under finite/presentable gluing
 -> prove density/nervousness
 -> reconstruct the world.
```

Testing whether this procedure recovers known arities in graphs, automata, linear/tensor systems, operadic/tree-like worlds, or other structures becomes a high-value external representation programme.
