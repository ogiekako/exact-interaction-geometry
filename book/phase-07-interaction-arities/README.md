# Phase VII — interaction arities

**Current status: generic arity shell CLOSED / KNOWN; project-specific interaction-arity theorem OPEN / REDUCED.**

Phase VII asks the strongest version of the reconstruction question:

> Can a small family of elementary local interaction probes reconstruct objects, morphisms, and the ambient mathematical world?

## Generic shell — prior art

For a small wiring category `W`, let

```text
C = PSh(W),
A_int = Kar(FinColim(yW)).
```

Then `A_int` is the category of finitely presentable presheaves and is dense. More generally, locally presentable worlds are reconstructed from their presentable arities.

For finitary/accessibly controlled monads, monads-with-arities / nervous-monad theory supplies fully faithful nerve theorems and essential-image/model characterizations.

This is the precise sense in which finite/presentable interaction probes can replace all-object Yoneda probes.

## Project-specific theorem still wanted

The important unresolved theorem is not “some dense probes exist”. It is:

> **The reduced interfaces actually forced by the Phase-IV process theory form the correct dense/nervous arities of the intended recurrent-process world.**

That requires an explicit world and explicit interaction probes, not choosing all finitely presentable presheaves after the fact.

## Finite residual-nerve theorem

One accepted finite theorem is already available. For a finite-index interaction tensor

```text
F : product_e D_e -> O,
```

the all-subset continuation residuals

```text
Q_A = im(D_A -> O^(D_(E-A)))
```

with their gluing maps form an exact extensional residual nerve that reconstructs `F`; on the stated typed-recoding groupoid the construction is fully faithful.

This is a concrete interaction-arity theorem, but it is not yet the full process-world density theorem above.
