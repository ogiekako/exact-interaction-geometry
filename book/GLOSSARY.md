# Glossary

## Raw execution
Execution data retained before neutralization, observer quotient, or effective projection. Depending on scope it includes complete storage configurations, payload/action state, occurrence identity, records, and observer state.

## Observer quotient `Omega_O`
The least-information fully abstract quotient for a declared observer/context family `O`. It is intentionally lossy and therefore distinct from the lossless structural representation used for exact reconstruction.

## Interface / separator
The data required to glue two local pieces while preserving the declared raw operations and future composition. It is not synonymous with “shared variables”.

## Compatibility proarrow
A Set-valued relation/witness object between private shore states. In the GPSH storage theorem,

```text
P_S(alpha,beta)=C(M_S) x Phase(|alpha|,|beta|)
```

records exactly which two private frame lists are jointly realizable and with which terminal separator heap/orientation.

## State interface vs dynamic interface
A state interface need only reconstruct global states from local data. A dynamic interface must additionally make local transition targets well typed. The latter can require strictly more synchronization data.

## Atlas / moduli of decompositions
The equivariant family/groupoid of admissible exact decomposition charts. It replaces a nonexistent natural choice of one preferred chart when automorphisms permute several equally valid decompositions.

## Factorization atlas
The collection/category of factorizations of an exact interaction object, schematically

```text
K ~= Q odot P.
```

A numerical resource is usually a valuation on this atlas rather than the primitive interaction datum itself.

## Flatness
Exact factorization through a prescribed middle object with no residual interaction defect, relative to a stated doctrine. The programme deliberately does not define one doctrine-free scalar flatness notion.

## Interaction curvature / defect
The failure of a canonical comparison map to be invertible after cutting, compressing, or recombining interaction data. Scalar submodularity slack is one possible valuation of such an object-valued defect in suitable sectors.

## Normal-lax `Prof` semantics
For `p:E->B`, executions lying over a boundary arrow `f` form a profunctor between the fibres over the endpoints. Composition of executions gives lax profunctor composition. This is the generic Phase-VI raw interaction shell.

## Conduche / pseudo sector
The case in which the lax comparison maps are invertible, corresponding to exact middle factorization up to the standard coend/fibre-zigzag equivalence.

## Residual quotient
For a finite interaction tensor

```text
F : product_e D_e -> O,
```

the quotient `Q_A` identifies assignments on `A` exactly when they induce the same continuation function on the complement.

## Interaction arity
A small local interaction shape used as a probe. In the generic presheaf shell, finite interaction arities are the finite-colimit/retract closure of elementary wiring representables. The project-specific goal is to derive the arities from the **actual reduced process interfaces**, not to choose a dense family after the fact.

## Nervous monad
A monad satisfying the generalized nerve theorem relative to a chosen dense arity category. For locally finitely presentable bases and all finitely presentable arities, finitary monads are the standard example.

## Opaque atom / residual
An exact recurrent object whose internal exhaustive effective classification is not supplied or is impossible, while its interface and compositional behavior remain explicit. “Opaque” is not synonymous with “semantically hard”.
