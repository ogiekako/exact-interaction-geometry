# Phase III — find the intrinsic object

**Status: completed as the transition from presentation-classification to structural-object research; individual subtheories have their own audit status.**

Phase III makes the decisive conceptual move:

> Is a fully producted Presburger atlas the mathematical object, or merely an overexpressive presentation language that mixes genuine interaction with arbitrary programmable arithmetic decoration?

The target object is required to be independently motivated, presentation-invariant under justified recodings, naturally compositional, reconstructive, decomposable, obstruction-bearing, and compatible with the Phase-I no-go.

## Falsification requirements

Any candidate has to survive:

- finite future quotients;
- one-counter compensated systems;
- benign higher-resource systems;
- annotated two-resource amplification;
- payload-dependent guards and divisibility;
- observation masking;
- the fixed scalar universal family;
- harmless presentation padding.

This phase explicitly rejects defining the intrinsic object by “whatever the compiler accepts”.

## Outcome

The search exposed transactional graph-product storage, compatibility proarrows, composition-first contextual semantics, and recurrent affine/action structure as load-bearing ingredients. Those discoveries were reorganized into the Phase-IV Graph-Minors-scale Grand Book.
