## Why each arrow is load-bearing

### I -> II
The non-r.e. theorem says that an unrestricted exhaustive classifier cannot be the final target. Phase II therefore asks for exact theorems on natural structural subdomains rather than another universal router.

### II -> III
The coastline theorems succeed for reasons that are not captured by one scalar width. Future legality, storage resource, affine action, and observation are separate axes. Phase III therefore changes the ambient object instead of adding one more compiler clause.

### III -> IV
Exact composition fails if residual storage/action state is projected away before gluing. The graph-storage object makes complete operational ports primitive. Phase IV then asks whether those complete ports factor through small, noncopying, structurally meaningful interfaces.

### IV -> V
GPSH separators and protected codescent show that exact interaction exists as a mathematical object, but not necessarily as one scalar. Phase V asks for the geometry of this interaction object and the conditions under which numerical uncrossing laws emerge.

### V -> VI
Once interaction is understood as intensional witness/proarrow data, the generic dynamic question becomes: which abstract interaction systems are realizable as execution categories? The classical answer is the normal-lax `Prof` / generalized Grothendieck shell.

### VI -> VII
A raw Grothendieck representation can be tautological: witnesses may still carry too much state. Phase VII therefore asks whether a **small generated family of reduced local interactions** suffices to reconstruct the whole world. That is a density/arity/nervousness question.

```text

          |                                      |
          | must reconstruct                     | intentionally lossy

```

and

```text
mathematical exactness --------------------> effective realization
          |                                      |
          | can exist without algorithm          | blocked by non-r.e. boundary
          v                                      v

```

Collapsing either pair is a recurring source of false theorems.
