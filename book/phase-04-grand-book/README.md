The full bare/representation-independent Grand Book is not declared reached. In particular:

- arbitrary invented recodings can form infinite antichains;
- the whole-state “separator” is exact but vacuous;
- a formal groupoid of all charts is not by itself a nontrivial `BOOK-BASE`;
- reduced/cofinal/non-copying admissibility remains a substantive theorem, not a definition.
