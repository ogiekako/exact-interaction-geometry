## 2. Exact graph-product storage separators

Take a finite graph-product storage monoid with

```text
V(Gamma)=A disjoint-union S disjoint-union B,
```

and no graph edge from `A` to `B`.

### GPSH normal form — **AUDITED / ACCEPTED**
Every right-invertible configuration has a unique reduced heap decomposition

```text
H = r_1 ... r_q t,
```

where `t in C(M_S)` is the terminal separator heap and the `r_i` are nonempty right-`S`-reduced shore frames whose owners alternate between `A` and `B`.

### Exact compatibility proarrow
For private frame lists `alpha,beta`,

```text
P_S(alpha,beta)=C(M_S) x Phase(|alpha|,|beta|).
```

Then

```text
C(M_Gamma)
 ~= disjoint-union_(alpha,beta) P_S(alpha,beta).
```

Relative to the fixed private projections, this is the reduced universal quotient of every exact extensional separator code.

This gives a precise meaning to separator information: **the minimal compatibility witness needed to zip two private histories into one future-bearing global state**, not merely a tuple of shared variables.

## 3. State reconstruction is not transition typing

A smaller equality-pullback base can reconstruct global states, but two states can have the same active private list and same small shared state while the same local push lands in different target shared states.

Thus

```text
state separator < dynamic separator
```

in general. A sufficient deterministic completion exists, but the exact owner-local dynamics is naturally a dependent span/proarrow: active-fibre update plus passive transport.

This is a principal reason Phase VI later lands in `Prof` rather than ordinary products.

## 5. No-choice and atlas-valued structure

A bare four-state null process can possess three nontrivial `2 x 2` Cartesian coordinate systems permuted transitively by automorphisms.
