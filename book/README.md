# The Interaction Reconstruction Book

This directory gives the shortest coherent route through the programme.

The phases are not merely chronological. Each removes a specific ambiguity left by the previous one.

1. [`phase-01-foundations`](phase-01-foundations/) — **What is the exact semantics, and what can no effective classifier possibly do?**
2. [`phase-02-effective-structure`](phase-02-effective-structure/) — **Which natural restricted sectors have exact effective structure?**
3. [`phase-03-intrinsic-object`](phase-03-intrinsic-object/) — **Are Presburger atlases the wrong ambient objects?**
4. [`phase-04-grand-book`](phase-04-grand-book/) — **What exact non-copying structure supports decomposition, reconstruction, torsos, and obstructions?**
5. [`phase-05-interaction-geometry`](phase-05-interaction-geometry/) — **How much interaction crosses an interface, and what laws govern that resource?**
6. [`phase-06-realizability`](phase-06-realizability/) — **Which abstract interaction objects come from genuine execution systems?**
7. [`phase-07-interaction-arities`](phase-07-interaction-arities/) — **When do small local interactions reconstruct the whole mathematical world?**

The current programme is deliberately two-level:

```text
generic categorical shell
    +
project-specific reduced interaction theory
```

The generic shell is now sharply understood in several places. The project-specific strong theorems remain the high-value frontier.
