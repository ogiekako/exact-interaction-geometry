# The Interaction Reconstruction Book

This directory presents the mathematical spine of the programme in seven phases. It is intentionally **not** a chronological archive. Failed candidates, repaired proofs, and detailed audit history live in the original research ledger; here we retain only the currently live statements and the counterexamples that explain why the theory has its present form.

## How to read this Book

Each phase is organized in the same order:

1. **Problem** — the mathematical question introduced at that phase.
2. **Objects** — the data that survive into later phases.
3. **Theorems** — theorem-scale statements, with status labels.
4. **Counterexamples / boundaries** — what stronger-looking statements fail.
5. **Dependency out** — why the next phase is forced.

Cross-cutting references:

- [`THEOREM_INDEX.md`](THEOREM_INDEX.md): compact theorem inventory.
- [`DEPENDENCY_GRAPH.md`](DEPENDENCY_GRAPH.md): dependency DAG and conceptual flow.
- [`COUNTEREXAMPLE_ATLAS.md`](COUNTEREXAMPLE_ATLAS.md): finite and structural anti-theorems.
- [`GLOSSARY.md`](GLOSSARY.md): recurring mathematical objects and notation.
- [`../STATUS.md`](../STATUS.md): conservative epistemic boundary.
- [`../provenance/SOURCE_MAP.md`](../provenance/SOURCE_MAP.md): immutable map to the original ledger.

## The seven-phase spine

```text
I. Exact semantics and optimal no-go
      |
      v
II. Effective structural coastlines
      |
      v
III. Intrinsic object / transactional graph-storage
      |
      v
IV. Grand Book: exact interfaces + decomposition + torsos + obstructions
      |
      v
V. Interaction geometry: exact resource first, scalar second
      |
      v
VI. Realizability: categories over boundaries <-> lax Prof
      |
      v
VII. Interaction arities: reconstruction from small local probes
```

The direction is important. Phase VII is not an abstract categorical layer placed on top of an unrelated dynamics project. The later objects are forced by failures discovered earlier:

- Phase I forbids an exhaustive scalar tame/wild classifier.
- Phase II shows that useful exact theorems nevertheless exist on natural structural coastlines.
- Phase III reveals that storage/configuration ports and transaction order are part of the object, not implementation noise.
- Phase IV shows that exact gluing is naturally dependent/proarrow-like and often atlas-valued.
- Phase V separates exact interaction from its numerical valuations.
- Phase VI identifies the generic dynamic reconstruction shell.
- Phase VII asks when the *small reduced interfaces actually generated by the process theory* are sufficient probes for reconstructing the world.

## Status convention

A theorem statement in this directory should be read together with its label:

- **AUDITED / ACCEPTED** — reconstructed or independently audited in the original ledger.
- **CLAIMED-PROVED; AUDIT PENDING** — a proof/certificate exists but has not been canonically promoted.
- **KNOWN / PRIOR ART** — standard external mathematics used as a shell.
- **REFUTATION** — a stronger proposed statement is false.
- **REDUCED / OPEN** — the remaining project-specific target after a generic shell has been identified.

The Book prefers a narrower audited theorem to a broader unaudited slogan.
