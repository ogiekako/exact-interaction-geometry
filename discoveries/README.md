# Concrete discoveries

This directory contains externally checkable mathematical discoveries that arose from the interaction/factorization viewpoint but are logically independent of the general EIG foundation.

They are included because they provide a stronger test than internal reformulation: the programme was used to make a concrete prediction about an existing mathematical question, and that prediction led to small exact counterexamples and then to a uniform family.

Current dossier:

- [`source-pair-augmentation.md`](source-pair-augmentation.md) — candidate negative answer to the Parnas--Shraibman Section-6 source-pair augmentation question for both Boolean and binary rank, plus an unbounded Boolean family.

## Status convention

These dossiers deliberately separate three questions:

```text
EIG correctness
    --not a dependency--> counterexample correctness

counterexample correctness
    --not a dependency--> historical novelty / priority
```

At the 2026-08-31 snapshot, the checked-in exact programs pass, but the external-discovery claims remain **pending an independent mathematical/program recheck and a fresh publication-level novelty audit** before public priority is asserted.
